# What is in this package

## Manuscript

| File | What it is |
|---|---|
| `manuscript/Manuscript_Subtype_Stability_Ceiling.docx` | The submission-ready manuscript: US Letter, 1-inch margins, Times New Roman 12 pt, double-spaced, continuous line numbers, page numbers top right, 17 numbered equations as editable text, 4 tables, 5 figure legends and the embedded figures. |
| `manuscript/Manuscript_Subtype_Stability_Ceiling.pdf` | The same document rendered, for reading and for checking layout. |
| `manuscript/manuscript.md` | The manuscript source. Citations are `[@key]` tokens resolved against the verified bibliography at build time, so renumbering is automatic if text is added or removed. |
| `manuscript/reference_list.txt` | The 52 references in order of first appearance, Vancouver style, as they appear in the manuscript. |
| `manuscript/build_docx.js` | Builds the DOCX from the Markdown source and the verified bibliography. |
| `manuscript/finalize_docx.py` | Post-processes the page-number field so it renders correctly outside Word. |

Placeholders that need your input are marked in square brackets: `[AUTHOR 1]`,
`[Affiliation 1]`, `[FUNDING …]`, `[GITHUB URL …]`, `[ZENODO DOI …]`. Everything
else is final text.

## Figures

`figures/figure1…figure5`, each as **PDF** (vector, for submission) and **PNG**
(600 dpi). They are generated by `code/12_figures.py` and are regenerated
end-to-end from the results files, so they cannot drift out of step with the
numbers in the text.

## Code and reproducibility (GitHub / Zenodo)

The whole repository is ready to publish as-is: `README.md`, `LICENSE` (MIT),
`CITATION.cff`, `requirements.txt`, `environment.yml`, `Makefile`, `.gitignore`,
`code/` and `results/`. `make all` reproduces every number from the public
archives; `make theory` re-runs only the closed-form/simulation check, which
needs no data and finishes in under a minute.

To publish:

```bash
cd repo
git init && git add . && git commit -m "Stability ceiling of connectome subtypes"
gh repo create <name> --public --source=. --push
git tag -a v1.0.0 -m "Version accompanying the manuscript" && git push --tags
```

Then connect the repository to Zenodo and publish the release to mint the DOI,
and paste the URL and DOI into the Data Availability Statement and `CITATION.cff`.

## Preregistration

`preregistration/PREREGISTRATION.md` plus `code/17_nda_adapter.py` — the
ready-to-run protocol for the infant-sibling collections. Deposit this with the
paper; it is what lets a group holding a data-use certification execute the
study unchanged, and it is the most likely route to a collaboration.

`results/nda_shortlist.md` lists the candidate collections with their numbers,
which is what a Research Data Use Statement has to name.
